# Foresight Diagnostics

> Foresight Diagnostics is a CLIA-certified, CAP-accredited cancer diagnostics company
> founded in 2020 in Boulder, Colorado by Stanford physicians and scientists, and since
> February 2026 a wholly owned subsidiary of Natera, Inc. Its Foresight CLARITY minimal
> residual disease (MRD) platform is a liquid-biopsy test powered by proprietary
> PhasED-Seq phased-variant sequencing, detecting circulating tumor DNA at an analytical
> sensitivity below one part per million across lymphoma, lung and other solid tumors.

## API surface

Foresight Diagnostics publishes **no public API**. There is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL specification, no SDK on any public package
registry, no MCP server, no A2A agent card, and no `/.well-known/` document. No
`api.`, `portal.`, `developer.`, `docs.`, `app.`, `results.`, `provider.`, `status.`
or `trust.` subdomain of `foresight-dx.com` resolves in DNS.

The company sells clinical laboratory testing services — biopharma trial support,
academic research collaborations and clinical MRD testing — not software. Ordering and
result delivery run through contracted laboratory workflows, not a public developer
program.

The only machine-readable endpoint on the domain is the stock WordPress CMS REST API at
`https://foresight-dx.com/wp-json/` (20 namespaces, 304 routes, all supplied by
WordPress core and its Elementor/Astra/Forminator/CookieYes plugins). It is content
management infrastructure for the marketing site, not a Foresight Diagnostics product
API, and it is deliberately NOT recorded as one.
